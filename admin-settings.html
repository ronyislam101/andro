General Settings
Wallet Transfer Settings
Set the minimum amount users must transfer. The value is saved as settings/transferSettings.minTransferAmount and can be displayed by the user wallet-transfer page.
Deposit Settings
Enable DepositControls the deposit feature setting.
Individual user deposit limits remain controlled from Admin Users. This page does not create a maximum deposit, matching the current deposit flow.
Package Discount
Enable Package DiscountApply one discount to every package in the user app.
Enter a value from 0 to 100. The user app will show the original price, discounted price and percentage, and will submit the discounted amount with the payment request.
Force Update
Force user app updateWhen enabled, the user login page is locked. Users must press Update Now and open the official Telegram update link.
